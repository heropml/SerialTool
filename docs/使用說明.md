## 1. 快速上手

1. 從 [Releases](https://github.com/heropml/SerialTool/releases) 安裝（見 [第 6 節](#6-安裝與系統需求)），桌面雙擊 **CommTool** 圖示啟動
2. 左側「連線設定」裡選**類型**（串口 / 網路 / Virtual）→ 填參數，點 **開啟串口 / 開啟 / 連線 / 開始監聽 / Start Virtual**
3. 右側「資料區」即時顯示收發內容，下方「傳送區」輸入要傳送的資料
4. 需要同窗多連線時用「新建會話」開多標籤（串口 / TCP / UDP / Virtual 可並發）

## ⭐ CommTool v1.6.0 協議流組幀 / 解析診斷

本版為 **v1.6.0**，在 v1.5.7 基線上把分析層接到完整協議幀（預設仍按收包，相容舊工程）：

- **協議幀模式** — 串口/TCP 黏包、拆包時按幀頭+長度組成完整幀，再餵幀解析 / 波形 HEX / 儀表板 HEX / 結構化記錄。設定獨立於自動應答（可套用其組幀參數）。UDP 預設一資料報一幀，可選擇也按流組幀。
- **TCP Server** — 半幀快取按用戶端隔離；斷開即丟棄該來源，避免埠複用把舊尾巴拼進新連線。
- **解析診斷** — 組幀對話框底部顯示計數；「沒有欄位」時可看最近失敗原因。
- **顯示 / 錄製** — 資料區、協議高亮、`.ctrec` 仍是原始收包。
- **即時日誌輪轉** — 先開啟新段再關舊檔；新段失敗則繼續寫舊段並提示，不再關掉即時日誌。
- **Linux** — 安裝器等本行程結束後再覆蓋安裝目錄；官方包僅 x86_64。
- **邊界** — 不做工作階段樹 / 分屏 / 拖出成窗；P2 繼續暫緩。本輪先發 Windows；macOS DMG 與 Linux `.run` 補同一 tag `comm-v1.6.0`。

## ⭐ CommTool v1.5.7 多用戶端 PCAP / 增量高亮 / Ctrl+Enter

本版為 **v1.5.7**，在 v1.5.6 基線上補 PCAP、高亮與傳送/日誌：

- **TCP Server 多用戶端 PCAP** — 多於一個對端（含定向回覆與 `__all__` 廣播）可匯出 `.pcap` / `.pcapng`；每用戶端獨立 4 元組；多於一個對端時匯出前確認；廣播按傳送當時的對端展開，後來才連上的用戶端不會被補進更早的廣播幀；舊單對端 `.ctrec` 仍可匯出。
- **關鍵字增量高亮** — 髒區間按文末累積，長工作階段頭部截斷不再漏高亮；終端模式納入規則指紋；`ESC[2J` 全清殘留選區。
- **搜尋節流** — 150ms 防抖；查詢未變跳過全文件掃描；文件增長則重建目前頁。
- **Ctrl+Enter 傳送** — Enter 仍換行；先提交 IME 組合；終端模式不變。
- **即時日誌** — 每次寫入後 flush，約 1 秒合併 fsync；磁碟滿仍關日誌；閒置同步異常不冒出計時器。
- **邊界** — 不做工作階段樹 / 分屏 / 拖出成窗；P2 繼續暫緩。Windows / macOS / Linux x86_64 安裝包已掛同一 Release。

## ⭐ CommTool v1.5.6 傳輸 / 回放 / 掃描 per-session

本版為 **v1.5.6**，在 v1.5.5 基線上補齊多工作階段引擎：

- **剩餘引擎 per-session** — 檔案傳輸 / 回放 / 裝置掃描 / 自動應答按啟動標籤獨立；開始 / 停止 / 播放跟目前標籤；關對話框結束所有工作階段對應任務。

- **修復** — 指令碼 I/O 釘住、超長截斷警告、傳輸超大檔案確認、傳輸完成不阻塞介面、背景 RX 異常列表、回放關閉順序、工作階段代理槽位對拍。

## ⭐ CommTool v1.5.5 多工作階段引擎 / 軟切標籤

本版為 **v1.5.5**，在 v1.5.4 基線上收口多工作階段引擎：

- **軟切標籤** — 獨占引擎釘在啟動工作階段，切換標籤放行、背景繼續；關閉忙碌標籤仍攔截（懸停提示佔用）。

## ⭐ CommTool v1.5.0 終端多工作階段標籤

## ★ CommTool v1.2.3 串口穩健性與欄寬記憶

- **串口選擇防亂跳** — 選中的串口被後台掃描偶發瞬時掉列舉時不再跳到別的口；口長期不在則自動移除「未偵測到」佔位、回落第一個真實口（不再常駐殘留項）。
- **串口被拔出自動斷開** — 已連線的串口連續幾次偵測不到（拔出 / 掉驅動）→ 自動斷開並提示「串口 X 已移除」，不再卡在"已連線"假象。
- **串口掉線不自動重連** — 串口斷開多為拔出 / 斷電的物理事件，重連無意義且可能連錯口，故串口掉線後乾淨斷開、不重連（網路 TCP / UDP 仍自動重連）。

## ★ CommTool v1.1.8 自動應答位元遮罩與欄位匹配

自動應答「匹配」做到**子位元組粒度**：除整位元組 `??` 通配，現在還能按半位元組 / 位元 / 欄位匹配：

- **位元遮罩 / 欄位級** — 匹配從「逐位元組精確 / 整位元組通配」升級為逐位元組 `(值, 遮罩)` 比對，命中需 `(收到位元組 & 遮罩) == (值 & 遮罩)`：

- **協定幀解析表**（標題列「幀解析」）— 把每個接收幀按規則解析成「名稱 = 值」表格。
  - **多幀多規則**：規則列表每行「幀頭 | 欄位定義」，每幀按幀頭前綴比對第一條命中的規則；
  - 「全部」標籤看混合幀流，另給每條規則一個分欄標籤；帶序號欄、原始幀欄；
  - 欄位支援數值型別 + `hexN`/`strN`，數值加 `x` 後綴按十六進位顯示；
  - Ctrl+C / 右鍵 複製·全選、匯出 CSV、暫停、欄寬可拖、捲動鎖定 +「↓最新」回底。
- 波形圖與幀解析共用同一套幀頭/欄位定義；新增相依 pyqtgraph + numpy（安裝包已內建）。三語介面同步。

## 2. 主要功能

### 2.1 連線設定

左上角「連線設定」卡片，第一行 **「類型」** 下拉提供共 **6** 個選項（新裝預設 **Serial 串口**）：

| 選項 | 說明 |
|------|------|
| **Serial** | 串口（COM 埠）收發 |
| **UDP** | 無連線收發 |
| **UDP Multicast** | UDP 群播 |
| **TCP Server** | 作為伺服器監聽，接受用戶端連入 |
| **TCP Client** | 作為用戶端連向遠端伺服器 |
| **Virtual** | 虛擬連線（無硬體；可回環；用於驗證與 `.ctrec` 回放） |

下方欄位**隨類型動態顯隱**：

- **Serial（串口）**
  - **串口**（下拉本機串口，旁邊 **⟳** 手動刷新；後台也會定時掃描熱插拔）
  - **鮑率**（可編輯下拉，常用 1200~2000000）
  - **資料位元**（5 / 6 / 7 / 8，預設 8）、**校驗位元**（None / Even / Odd / Mark / Space）、**停止位元**（1 / 1.5 / 2）
  - 點 **「開啟串口」** 連線
- **UDP**
  - **本地IP**（下拉，列出本機網卡 IP，`0.0.0.0` = 所有網卡）
  - **本地埠**
  - **指定遠端**開關 — 關＝回覆最近發來資料的對端；開＝啟用下面的 **遠端IP / 遠端埠**，固定發往該位址
    - **關**模式下每收到一包資料，會把灰顯的「遠端IP / 遠端埠」自動刷成**最近發來方的位址**（讓你看到目前在跟誰通訊、傳送會回覆給誰；對端變化才刷）。收到某方的封包後想固定回它，直接開啟「指定遠端」即預填好該位址
- **UDP Multicast（群播）**
  - **本地IP**（出 / 入網卡，`0.0.0.0` = 預設）
  - **群播位址**（如 `239.0.0.1`，須落在 `224.0.0.0` ~ `239.255.255.255`）
  - **本地埠**
- **TCP Server**
  - **本地IP**、**本地埠** →「開始監聽」
  - 有用戶端連入後出現 **「目標」** 下拉，可選某個用戶端或 **「全部」**（廣播）來傳送
- **TCP Client**
  - **遠端IP**（必填）、**遠端埠**（必填）→「連線」
- **Virtual（虛擬）**
  - 可不接硬體直接啟動；可選 **回環**
  - 用於驗證自動應答 / 腳本 / 序列，以及會話錄製回放時的注入落點

**動作按鈕**文案隨類型 + 狀態變化：

- Serial：開啟串口 / 關閉串口
- UDP / UDP Multicast：開啟 / 關閉
- TCP Server：開始監聽 / 停止監聽
- TCP Client：連線 / 中斷
- Virtual：Start Virtual / Stop Virtual

連線建立後整張卡片**鎖定變灰**；隨協議停用的輸入框也會變灰。

### 2.2 資料接收

收發同框顯示，箭頭區分方向：

| 標記 | 含義 |
|------|------|
| `← 收` | 接收到的資料 |
| `→ 發` | 傳送出去的資料 |

**顯示選項**（資料區卡片）

- **顯示方式** — 文字 / HEX / HEX 轉儲 / 數值（互斥）；收發一致，與「HEX 傳送」無關。轉儲可選列寬；數值可選型別與位元組序
- **自動換行** — 行超長自動換行，關閉後右側捲動條
- **字元編碼** — 選 自動 / UTF-8 / GBK / GB2312 / GB18030 / Big5 / ASCII / Latin-1 共 8 項；影響 RX 解碼 / TX 文字編碼 / 檔案載入
- **顯示時間戳** — 每個新區塊前加 `[2026/06/03 09:48:54 023]`，同時顯示 ← / → 方向箭頭
- **時間分包** + **逾時 ms** — 兩次接收間隔超過設定毫秒就開新行（預設 20ms，適合 Modbus）
- **換行分包** + **換行符模式** — 按 `\r\n` / `\r` / `\n` 切行
  - **自動**：三種風格全識別（Windows + Linux + Mac 相容）
  - **CRLF / LF / CR**：只認指定換行符，嚴格模式
- **即時記錄** — Xshell 風格連續日誌寫到 `.log` 檔案，**顯示什麼寫什麼**（帶時間戳、箭頭、HEX/ASCII）
  - **按檔案大小分包** — 開關旁下拉可選 不分包 / 1M / 2M / 5M / 10M / 20M / 50M / 100M，也可手填自訂（如 `3M`、`500K`）；寫到設定大小自動切到新檔（原名加 `_001`/`_002`…）
- **最大行數** — 顯示行上限，超出自動丟棄最舊的（防止長跑卡頓）；**不影響日誌檔案**
- **只顯高亮行** — 開啟後只保留命中關鍵字高亮規則的行，其餘隱藏；方便在大量資料裡只盯關鍵內容

**捲動鎖定 / 自動跟隨**

- 資料停在底部時自動跟隨最新資料；一旦**往上捲**，畫面就定住不再被新資料頂走，但新資料**照常接收**、不會漏
- 右下角浮動 **「↓ 最新」** 按鈕：點一下回到底部並恢復自動跟隨

**單擊高亮**

- 單擊資料區任一行即高亮整行，方便鎖定一筆關鍵收 / 發；再點一下取消

**字號** — 右上角 `A−` `A+` 微調（7~28pt），適配大螢幕 / 小螢幕

**儲存 / 清空** — 卡片底部按鈕，儲存為 `save_log_YYYYMMDD_HHMMSS.log`

**協議幀解析**（標題列「功能 → 幀解析」）— 預設每個收包當一幀。串口/TCP 黏包、拆包時勾選 **協議幀模式**，按幀頭+長度欄位組完整幀後再解析（波形 HEX / 儀表板 HEX / 結構化記錄共用）。UDP 預設一資料報一幀。顯示區與 `.ctrec` 仍是原始收包。對話框底部有解析計數；「沒有欄位」時可看最近失敗原因。

**右鍵選單** — 在資料區按右鍵彈出 複製 / 全選 / 清空 / 儲存，以及 **轉為文字 / 轉為 HEX**（選區互轉，結果彈窗 + 剪貼簿，上限 64 KiB）；選單文字跟隨程式語言

### 2.3 資料傳送

- **HEX 傳送** — 輸入的 16 進位字串按位元組傳送，下面寫法都識別：

| 寫法 | 解析 |
|------|------|
| `AA BB CC DD` | 4 位元組 |
| `AABBCCDD` | 4 位元組 |
| `AA-BB-CC-DD` | 4 位元組 |
| `AA:BB:CC:DD` | 4 位元組 |
| `0xAA 0xBB 0xCC` | 3 位元組 |
| `// 註解\nAA BB` | 2 位元組 |
| `/* 區塊註解 */ AA BB` | 2 位元組 |

  非法字元（如 `AA ZZ BB`）會拒絕傳送並提示格式錯誤。

- **Ctrl+Enter 傳送** — 普通傳送框 Ctrl+Enter 傳送，Enter 仍換行（終端模式不變，Enter 透傳）
- **追加換行** + **換行符模式（CRLF / LF / CR）** — 每次傳送自動追加換行符（AT 命令場景常用）
- **定時傳送** + **週期 ms** — 週期性自動傳送目前內容，最小 10ms；傳送失敗時（未連線 / 資料格式錯誤 / 無目標等）自動停止
- **校驗**（9 種演算法 +「無」）— 傳送前在末尾追加校驗位元組

| 演算法 | 位元組 | 用途 |
|------|------|------|
| 無 | 0 | 不追加 |
| 和校驗 / ADD8 | 1 | 簡單累加和 |
| 累加和取反 / ~ADD8 | 1 | 累加和按位取反 |
| 異或 / XOR8 | 1 | 全位元組異或 |
| CRC8 | 1 | 多項式 0x07（標準 CCITT）|
| **MOBUS** | 1 | **CRC8 多項式 0x31**，國內嵌入式常用 |
| ModbusCRC16 | 2 | Modbus RTU 標準，小端 |
| CCITT-CRC16 | 2 | CRC-16/CCITT-FALSE，大端 |
| CRC32 | 4 | Ethernet / ZIP 標準 |
| ADD16 | 2 | 16 位元累加和 |

**讀取檔案** — 直接把檔案內容塞進傳送框（HEX 模式自動轉 hex 字串）

**多條發送** — 傳送區「多條發送」按鈕開彈窗，一次管理多條常用資料、可勾選後迴圈輪發，詳見 [2.5 多條發送](#25-多條發送)

### 2.4 關鍵字高亮

資料區標題列 **「關鍵字高亮」** 按鈕開彈窗，按關鍵字替指定的收 / 發內容自動上色：

- **多條關鍵字**，每條可設**獨立顏色**
- 每條可選 **「背景」** 或 **「文字」** 上色方式
- 每條可限定生效**範圍**：收 / 發 / 收發
- 子字串比對，**區分大小寫**；自動跳過時間戳，不會誤把時間戳染色
- 規則**持久化**，下次啟動沿用

**分組／規則集** — 同一批關鍵字可整理成多個分組，按場景隨時切換：

- 彈窗左側為**分組列表**，可**新增** / **重新命名（雙擊）** / **刪除**分組
- 資料區標題列的**分組下拉**選擇哪個分組生效，含 **「（關閉）」** 項一鍵停用全部高亮
- 在彈窗裡**編輯的分組**與目前**生效的分組**相互獨立，編輯時不影響目前顯示

搭配資料區標題列的 **「只顯高亮行」** 可切換按鈕（開啟時高亮），可只保留命中關鍵字的行、隱藏其餘，從大量資料裡快速聚焦關鍵內容。

### 2.5 多條發送

傳送區 **「多條發送」** 按鈕開彈窗，集中管理多條常用資料：

- 每行一條資料，前面帶**核取方塊**
- 每行可**獨立設定** HEX / 換行 / 校驗，並可填 **「名稱」** 與 **「延時（ms）」**
- 勾選多條後 **「迴圈發送」** 按設定間隔依次輪發
- 條目**持久化**，下次啟動沿用

**分組** — 彈窗左側為**分組列表**，可**新增** / **刪除** / **雙擊改名**，把不同場景的常用命令分開管理。

**主介面快捷列** — 不必每次開彈窗，發送區上方一行直接操作：

- 一行 = `[多條發送（編輯）]` `[▶迴圈]` `[分組下拉]` ＋ 該分組每條命令平鋪成按鈕
- 點任一命令按鈕**直接發送**那條
- 按 **`▶迴圈`** 依目前分組各行的 **「延時」** 依次輪發

### 2.6 介面

- **視窗邊框**：Windows / Linux 為無邊框自繪標題列 + 圓角卡片與柔和陰影；macOS 使用系統原生標題列
- **緊湊版面** — 字號、輸入框、滑動開關、卡片間距全面縮小，同一畫面放得下更多內容
- 左側 sidebar（連線/資料/傳送設定）+ 右側資料區，分隔條**可拖曳**
- Windows：拖曳標題列移動視窗、雙擊切換最大化；邊緣原生縮放

系統匣圖示**右鍵選單**新增 **「關於」** 入口，開啟 **「關於」對話方塊**：裡面顯示應用圖示、名稱、目前版本號、簡介，以及一個 **「檢查更新」** 按鈕。

- **檢查更新** — 點擊後自動從更新來源讀取最新版本，並與目前版本比對：
  - **有新版本** → 對話方塊顯示新版本號、**更新說明** 與 **「下載並更新」** 按鈕。點擊開始下載（帶**進度百分比**）。

### 2.12 設定自動儲存

退出時自動存到安裝目錄的 `settings.ini`，下次啟動**完全還原**：

- 視窗位置 + 大小（含最大化狀態）
- 分隔條位置
- 目前語言 + 主題
- 所有開關 / 輸入框 / 下拉選項
- 傳送框內容、字號、最大行數

安裝目錄唯讀時（比如 Program Files 裝的非管理員執行），設定自動回退到 `%APPDATA%\CommTool\settings.ini`。

## 3. 實用技巧

- **Modbus 除錯**：顯示方式選 HEX + HEX 傳送 + 時間分包（20ms）+ ModbusCRC16
- **AT 命令除錯**：顯示方式選文字 + 追加 CRLF + 換行分包（自動）
- **長跑監控**：開即時記錄 → 日誌檔案可後續 Notepad++ / VS Code 開啟分析
- **HEX 寫註解**：HEX 傳送框可寫 `// 行註解`、`/* 區塊註解 */`、`# 行註解`，提交時自動移除
- **拖曳版面**：左右 / 上下分隔條都可以拖，調成順手的比例後下次啟動保留

## 5. 常見問題

**Q：TCP Server 開始監聽失敗 / 埠被佔用？**
A：該埠被其他程式佔用，或需要權限；換個埠或關掉佔用程式。

**Q：TCP Client 連不上？**
A：檢查遠端 IP / 埠是否正確、對端是否在監聽、防火牆是否放行。

**Q：UDP 點傳送提示「無可發送目標」？**
A：沒開「指定遠端」且還沒收到任何對端資料；開啟「指定遠端」填好遠端位址，或等對端先發一包。

**Q：UDP 群播收不到資料？**
A：確認防火牆放行、收發在同一群播位址和埠、在同一網段 / 網卡。

**Q：定時傳送不運作？**
A：週期最小 10ms，且必須保持連線；中斷時定時會自動暫停。

**Q：中文顯示亂碼？**
A：自動模式預設 UTF-8 優先，亂碼會自動回退 GBK。如果還是不對，裝置可能用其他編碼（如 Big5），在「字元編碼」下拉裡明確指定，或把顯示方式切到 HEX / HEX 轉儲看原始位元組。

**Q：HEX 傳送報「長度必須為偶數」？**
A：HEX 是按位元組解析的，`AA B` 是 3 個 hex 字元無法配對，補成 `AA 0B` 或 `AAB0` 即可。

**Q：日誌檔案大了會卡嗎？**
A：寫入是追加模式，幾十 MB / 幾百 MB 都不會卡。「最大行數」限制只影響**介面顯示**的行數，不影響日誌寫入。

## 6. 安裝與系統需求

安裝包從 [GitHub Releases](https://github.com/heropml/SerialTool/releases) 下載。目前正式版 **v1.6.0**。國內也可從 [Gitee Release](https://gitee.com/heropml/SerialTool/releases/tag/comm-v1.6.0) 取 **Windows Setup**（Gitee 不放 Mac / Linux 包）。

### Windows

- 系統：Windows 10 / 11（64 位元）
- 建議：`CommTool_Setup_v1.6.0.exe` — 精靈安裝，可選桌面捷徑；目前使用者安裝無需系統管理員
- 便攜：`CommTool_v1.6.0.exe` — 免安裝，首次啟動自解壓約 1–2 秒

### macOS

- 僅 **Apple Silicon**（arm64）：`CommTool_v1.6.0.dmg`
- 開啟 DMG，把 CommTool 拖進「應用程式」
- 若提示「已損壞，無法打開」（未公證），在終端執行一次：

```bash
xattr -dr com.apple.quarantine /Applications/CommTool.app
```

### Linux

- **x86_64**，glibc ≥ 2.27（Ubuntu 18.04+ / 多數麒麟）。xcb / X11 已打進包，一般不必再 `apt`
- 檔案：`CommTool_Setup_v1.6.0_linux_x86_64.run`

```bash
chmod +x CommTool_Setup_v1.6.0_linux_x86_64.run
./CommTool_Setup_v1.6.0_linux_x86_64.run
```

- 預設裝到 `~/.local/opt/CommTool`（**無需 sudo**），並寫入應用程式選單與桌面圖示
- 啟動：選單 / 桌面圖示，或 `~/.local/opt/CommTool/CommTool`（若 `~/.local/bin` 在 PATH 也可直接 `CommTool`）
- 解除安裝：`~/.local/opt/CommTool/uninstall.sh`
- 串口列表為空：把目前使用者加入 `dialout` 組後重新登入：`sudo usermod -aG dialout $USER`

磁碟約 100–200 MB。
