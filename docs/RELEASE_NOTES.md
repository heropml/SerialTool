**CommTool** 串口调试助手 / 网络调试工具（UART + RTT + TCP/UDP）。**v1.8.6** 优化串口接收与 20ms 分帧时序，增加静默组帧缓存上限。

## v1.8.6 更新内容

### 串口接收与分帧

- 后台阻塞等待首字节，消除原有 10ms 空闲轮询等待，并合并驱动缓冲区中已到达的尾部数据。
- 每个接收块使用整块读取完成时的单调时间戳，时间分包显示与自动应答静默组帧按该时间戳判断间隔。
- 使用精确定时器并复核截止时间，界面排队时先处理待交付数据，避免将界面处理延迟算成接收间隔。
- 首次读取到数据就登记接收活动，避免补读期间提前结束上一帧。补读失败仍交付已经读取的数据，关闭串口时取消阻塞读取。

### 静默组帧容量

- 自动应答静默组帧每会话上限 1MiB，超限时提示并丢弃整个超长帧，连续尾部数据等待静默间隔后再恢复匹配。
- 断开连接、编辑规则或重置缓冲时同步清除溢出状态，各会话独立。
- 时间分包控制显示，自动应答须单独设置规则静默时间。常用静默时间可设为 20ms，gap=0 继续按接收块即时匹配。

### 文档与验证

- README、简体中文、繁体中文、English 使用说明和 9 个随包示例同步为 v1.8.6。
- 完整回归 1831 项通过、8 项跳过、295 个子测试通过。
- Windows 串口与多会话定向测试 186 项通过、3 项跳过，Setup 隔离目录安装、已安装应用启动及卸载验证通过。macOS DMG 签名与打包后启动验证通过，Linux 安装包通过 Ubuntu 18.04 隔离目录安装和离屏启动验证。
- 伪终端覆盖空闲后突发数据、逐字节到达、界面延迟、补读暂停与异常，以及超限丢弃和恢复。真实 USB 串口与 Windows 时序仍需设备实测。

## 下载与安装

| 平台 | 文件 | 安装方式 |
|------|------|----------|
| Windows 10/11（64 位） | `CommTool_Setup_v1.8.6.exe` | 向导安装，可创建桌面快捷方式 |
| macOS（Apple Silicon） | `CommTool_v1.8.6.dmg` | 打开 DMG，拖入“应用程序”安装 |

Linux x86_64 使用 `CommTool_Setup_v1.8.6_linux_x86_64.run`，安装到 `~/.local/opt/CommTool`，要求 glibc ≥ 2.27（Ubuntu 18.04+）。

> 三个平台安装包在 [GitHub Release](https://github.com/heropml/SerialTool/releases/tag/comm-v1.8.6) 提供，并同步到 Gitee。本版 Linux `.run` 约 75MB，低于 Gitee 单文件 100MB 上限。

RTT 需另装 SEGGER J-Link 驱动。
