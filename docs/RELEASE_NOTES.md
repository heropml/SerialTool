串口 + 网络一体调试工具。本版围绕「没有硬件也能干活」：**虚拟连接、数据录制 / 回放、命令 DSL**。

## 1. 虚拟连接

「类型」下拉新增 **`Virtual`**：不接任何硬件也能启动一条连接。因为它的接口与串口 / 网络完全一致，**自动应答、自动化序列、脚本控制台、波形图、数值仪表盘、协议高亮全部照常可用**。

打开「回环」后，你发出去的数据会原样当成收到的回来——出差路上、设备还没到手时，就能把自动应答规则和脚本先写好并验证跑通。

## 2. 数据录制 / 回放

菜单栏「功能 → 数据录制 / 回放」：把线路上的**原始收发流连同时序**录下来，存成 `.ctrec` 文件（JSON Lines 文本格式，可读、可 diff、可手改）。之后按原始节奏重新注入，可调 **0.5x ~ 最快**倍速、可循环。

现场抓一次，回家慢慢复现；也能把问题现场打包发给同事。与宏录制分工明确：**宏录「你发了什么」产出脚本，本功能录「线路原始字节」产出数据**。回放落点是虚拟连接——往真实串口注入「收到的数据」物理上不成立，未连虚拟连接时会明确提示。

## 3. 命令 DSL

发送框里直接写时序，不必为了一段临时自动化去开脚本控制台：

```
AT\r\n\!(Delay500)AT+VER\r\n     先发 AT，等 500ms 再发 AT+VER
\!(Repeat3)PING\!(Delay200)      发 PING 等 200ms，整体重复 3 次
```

另有 `\!(Wait)`（同 Delay）、`\!(Hex)` / `\!(Text)` 切换后续段的发送格式。**不写指令时完全按原样发送、行为一字不变**。

## 4. 任务互斥扩展

录制 / 回放 / DSL 一并纳入统一占用表，与脚本控制台、自动化序列、文件传输、定时发送、Modbus 主机互斥：已有任务占用收发流时，另一项启动会明确提示，不会两路同时抢线路导致串帧。
