**CommTool** 串口调试助手 / 网络调试工具（UART + RTT + TCP/UDP）。**v1.8.7** 接入可切换的 QSerialPort 后端，并修复打包环境的更新证书验证。

## v1.8.7 更新内容

### 通用串口后端

- 主窗口和串口桥接共用连接接口，默认使用独立 Qt 线程中的 QSerialPort。
- 启动前设置 `COMMTOOL_SERIAL_BACKEND=pyserial` 可切换后端，便于同设备对照验证。后续库可通过实现连接协议并加入注册表接入。
- 接收数据携带读取时的单调时间戳，上层使用该时间戳进行 20ms 静默组帧。
- 发送返回 Qt 接受入队的字节数，采用 4MiB 输出积压上限。写失败会清空输出队列并关闭端口。

### 线路错误、在线改参与资源清理

- Parity / Framing / Break 线路错误允许连接继续接收。
- 可选控制线操作产生的同步 UnknownError 在操作范围内处理，读取状态线失败返回未知状态，Break 定时复位失败记录日志。
- 明确拒绝 macOS 的 Mark / Space 校验及 POSIX 的 1.5 停止位。
- 在线参数被驱动拒绝且成功回滚时，发出非致命提示并恢复参数控件，保留有效的连接签名与 Modbus 就绪状态。
- 参数回滚失败或实际读写故障时，清理端口、工作线程和连接状态。
- 参数控件恢复增加连接签名判空，打包缓存加入 Git 忽略规则。

### 更新证书

- 更新检查在默认系统信任库基础上加载 certifi 根证书，修复部分 macOS 打包环境的本地签发机构验证失败。
- 运行时依赖及打包配置同步包含 certifi 和 QtSerialPort。

### 文档与验证

- README、简体中文、繁体中文、English 使用说明及 9 个随包示例同步源码版本。
- macOS 完整回归 1896 项通过、8 项跳过、295 个子测试通过，`ruff check src tests scripts` 通过。
- Windows 后端定向测试 39 项通过、17 项跳过。PTY 与模拟驱动覆盖控制线失败、参数回滚、输出阻塞和线程清理。
- 真实 USB 串口的 CTS 阻塞、线路噪声与跨平台驱动兼容性需设备实测。
