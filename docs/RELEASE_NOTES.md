**CommTool** — 开源串口调试助手 / 网络调试工具（UART + RTT + TCP/UDP）。**v1.8.2 正式版**：弹窗全面主题化统一，发送区粘贴只取纯文本。

## v1.8.2 正式版

### 弹窗全面主题化

- 清理最后一批原生弹窗，统一为主题化对话框：按钮文案跟随简体中文 / 繁體中文 / English，配色跟随当前主题。
- 删除连接预设的确认框；帧构造器保存模板、Modbus 主机新增轮询视图、脚本控制台重命名的命名输入框。
- 主窗口创建前的「最多同时打开 8 个窗口」提示同样主题化，语言与主题从配置读取。

### 发送区粘贴修复

- 发送框粘贴 / 拖放只取纯文本：从网页、Word 等复制的 HEX 不再带入底色、字体、超链接等富文本格式。

### 文档与兼容性

- README、简体中文 / 繁體中文 / English 用户说明、架构与排期同步。
- 不涉及连接协议、收发行为与配置格式；无新依赖。

### 发布范围

- 本次发布 **Windows 安装版和单文件版**，tag 为 `comm-v1.8.2`。
- macOS（Apple Silicon）和 Linux x86_64 本版本待补包，更新清单暂不提供对应的新版本自动下载地址。
