串口 + 网络一体调试工具。本版围绕「工程可携带、设备定义可复用、采集数据可追溯」：**工作台工程化、设备定义与 Modbus 扫描中心、结构化数据记录、工程资源包**。

## 1. 工作台与工程

终端、协议、仿真、自动化、数据和桥接拆成独立工作台页面；工程菜单提供新建、打开、保存、另存为、最近工程和启动恢复。`.ctproj` 升级至 v2，显式携带寄存器表、发送模板/多条发送分组、序列、脚本和仪表盘设置，并保持对 v1 工程的读取兼容。

> 旧 v1 工程未携带寄存器表或模板库资源时，打开后这两项会按该工程的空资源初始化。如需保留当前共享内容，请先导出或另存为 v2 工程。

## 2. 设备定义与 Modbus 扫描中心

在「协议」工作台打开设备中心，维护从机、功能码、地址、类型、字节序、倍率、偏移和单位；寄存器表可 CSV 导入导出。扫描中心支持从机地址及 03/04 寄存器区间扫描，成功项可直接加入寄存器表。

扫描会暂时接管 Modbus 半双工调度器，同时隔离旧 RTU 在途响应、锁定冲突的主机设置，并在完成或取消后恢复原轮询配置、结果及持久化状态。单次扫描上限为 512 个目标，避免大范围扫描卡住界面。

## 3. 结构化数据记录

Modbus 响应会按寄存器表转换为命名标签，普通协议会按帧解析字段记录。结构化记录支持开始/停止、来源和关键字筛选、CSV 保存/载入以及按原时间轴回放；原始 `.ctrec` 仍用于字节级现场复现，两者互不替代。

> **macOS 首次打开提示「已损坏，无法打开」**：把 app 拖进「应用程序」后，在终端运行一次 `xattr -dr com.apple.quarantine /Applications/CommTool.app` 即可正常打开（仅 Apple Silicon）。
