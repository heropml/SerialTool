串口 + 网络一体调试工具。本版新增**帧构造器**：按字段组装协议帧、自动计算长度和校验，实时得到可发送的完整 HEX。

## 1. 字段化拼帧

菜单栏「功能 → 帧构造器」支持 u8/i8/u16/u32/f32 等带大小端数值、ASCII 和原始 HEX。每行一个字段，底部实时显示完整 HEX 和字节数；非法输入会阻止填入或发送。字段行可拖住左侧手柄排序（顺序即字节序），名称/类型/值三列的列宽也可拖拽调整。

## 2. 自动长度与校验

长度字段自动统计其后字节数；校验字段自动覆盖其前全部数据，支持 ADD8、XOR8、CRC8、Modbus CRC16、CCITT CRC16、CRC32、ADD16 等算法。直接发送按构造结果原样发出；填入主发送框后仍遵循主界面可见的追加换行/校验选项。

## 3. 内置协议模板

提供 Modbus 读保持寄存器、Modbus 写单寄存器和 AT 命令模板；模板载入后仍可逐字段修改。字段定义自动保存，并随配置导入/切换正确刷新。

## 4. 数据区滚动修复

修复数据区已有选区且用户向上翻看时，新数据到达会把视图拽到选区或底部的问题；贴底状态仍会正常跟随最新数据。
