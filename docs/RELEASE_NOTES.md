串口 + 网络一体调试工具。本版围绕「看得更清、改得更快、比得出差异」：**数值视图、选中即算校验和、动态改串口参数、日志增强、会话比较**。

## 1. 数值视图

显示设置新增开关：把收到的字节流按 **u8 / i8 / u16 / i16 / u32 / i32 / f32 × 大端 / 小端**（共 12 种组合）解读成数值序列，看 ADC 采样、传感器原始值时不必再手动换算。

凑不满一个数的尾部字节会**留到下一包继续拼**——串口上一个 u16 被拆到两个收包里是常态，跨包不会错位。列宽按类型固定，前后各包纵向对齐成列，便于竖着扫读。与 HEX 转储互斥（都接管整个数据区）。

## 2. 选中即算校验和

在数据区**选中一段字节，状态栏就地显示校验结果**，不用再复制去工具箱粘贴。状态栏直出 Modbus / XOR / SUM 三种，鼠标悬浮弹出**全 9 种**（和校验、累加和取反、异或、CRC8、Modbus-CRC16、CCITT-CRC16、CRC32、ADD16、MOBUS）的主题化卡片。

字节还原会自动跳过时间戳、方向箭头、HEX 转储的偏移列与 ASCII 列；文本 / 数值 / 终端视图无法无损还原原始字节，会明确拒算而不给貌似可信的错值。

## 3. 动态改串口参数

串口连接**期间**即可改波特率 / 数据位 / 校验位 / 停止位 / 流控，**不断开连接、不丢接收缓冲**——试未知设备波特率时逐个切换，比每次断开重连快得多。参数一次性原子应用，中途失败自动回滚，不会留下「硬件跑一半新参数」的中间态。（换端口 / 换协议仍需重新连接。）

## 4. 日志增强

实时记录的文件名支持变量：**`%date`**（20260724）/ `%time` / `%datetime` / **`%port`**（COM3 等）/ `%n`（分包序号）。例如 `log_%date_%port.txt` → `log_20260724_COM7.txt`。

文件名含日期变量时，**跨自然日会自动切换到新文件**（按天归档，序号归零）——挂机记录、现场值守时，下午开始记录、次日零点即自动分档。与原有的按大小分包并行工作。

## 5. 会话比较

菜单栏「功能 → 会话比较」：选两个 `.ctrec` 录制文件逐条对齐，比出**相同 / 内容不同 / 仅 A 有 / 仅 B 有**，配对成功的还报时序偏差。新旧固件各录一次，直接回答「这版改了什么」。

对齐用最长公共子序列（线性空间实现，省内存）：某一边少答一帧时**只报这一处**，后续继续对齐，不会像按下标并排那样整体错位。时间不参与是否相同的判定（同一帧早几十毫秒到达仍算同一帧），完整结果可导出 CSV。
