串口 + 网络一体调试工具。**v1.4.0 正式版**：在轻量、稳定、好用的定位下，落地寄存器扩展、Modbus 多视图与网关、触发动作链，并完成多轮外部审核收尾。

## v1.4.0 正式版

### 能力
- **寄存器扩展**：64 位类型、位域、0/1 地址基、预警/告警级别；贯通设备中心、结构化记录与仪表盘着色
- **Modbus 主机多视图**：按视图分组编辑，共用半双工引擎；提交时按全局下标原地合并
- **FC22 掩码写 / FC43/14 设备标识**：主机、从机、UI 与单测对齐
- **触发动作链**：Webhook / 外部程序 / 命中阈值；并发上限与导入门禁；退出回收进程组；单动作最长 30s
- **Modbus TCP↔RTU 网关**：多客户端独立重组与定向回包；超时回 0x0B；超时后恢复窗口（默认 200ms）防止迟到响应串扰；同批噪声后的合法帧不会因重同步片上限被卡住

### 稳定性与安全
- 连接中被关掉不再误报「对端已断开」；SEND_NO_TARGET 不再报成发送失败
- run_cmd 占位符值做 shell 转义；atexit 兜底回收子进程
- 触发器删除一律确认；删除主机视图前确认
- 仪表盘清除/改模式后刷新定时器保持运行
- Webhook 拒绝字面量私有/回环/链路本地地址（含 IPv4-mapped IPv6）

### 测试
- 基线：**1023 passed / 3 skipped / 291 subtests**
