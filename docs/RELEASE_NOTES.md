**CommTool** — 开源串口调试助手 / 网络调试工具（UART + TCP/UDP）。**v1.5.5 正式版**：多会话引擎收口——软切标签、后台 RX 喂本会话引擎/AR/触发器，序列与脚本/MBM/录制等按会话独立。

## v1.5.5 正式版

### 软切标签
- 切到其它标签不再被硬拦，各标签自己的任务继续跑
- 关闭仍在跑任务的标签会拦截，标签悬停提示当前占用（`session_tip_engine_busy`）
- 定时发送、多条循环发送仍按会话独立，切标签后台继续

### 后台 RX 喂本会话引擎
- 非活动标签收到的数据会喂给该会话的自动应答、序列、脚本、Modbus 主机、录制等
- 触发器按会话隔离解码流，后台 RX/TX 也会匹配
- 绘图、组帧、仪表盘仍只跟活动标签，避免后台噪声刷当前视图

### 按会话独立的运行态
- **序列 / 脚本 / Modbus 主机 / 录制 / 宏 / 发送 DSL**：每个标签可各自运行
- **Modbus 从机 bank**：每个会话一份寄存器；窗口共享从机配置，改配置时重建全部会话 bank
- **自动应答**仍为窗口开关，命中后按本会话发出
- 序列对话框结果列跟当前标签；汇总行可看到其它标签正在跑的序列（Run/Stop 仍只作用于当前标签）

### 仍整窗一份、钉会话的工具
- 文件传输、回放：同窗各一份，钉在启动会话；传输运行中其它标签点「开始」会被拦住
- 设备扫描：同窗一次（临时接管主机规则），占用记在启动标签

### 产品边界
- 本版不做会话树、拖拽分屏、标签拖出成窗
- P2（CLI / REST / 插件 dissector）继续暂缓
- macOS DMG 仍由协作者在 Mac 上跑 `release_macos.sh` 补到同一 Release；门禁通过前检查更新不提供 Mac 下载

### 测试
- 基线：既有套件 + 多会话软切 / 后台 RX / 序列与从机 bank / 传输启动门禁等新增用例（以 CI 为准）
