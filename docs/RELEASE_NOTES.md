串口 + 网络一体调试工具。本版新增**多窗口**——可同时开多个独立窗口、各调各的设备、互不干扰，并可管理（打开 / 切换 / 删除）多套配置。

## ✨ 新功能 / 改进

- **多窗口（独立配置）** —— 现在可以同时开多个 CommTool 窗口：
  - **新建窗口** —— 「帮助 → 打开配置 → 新建窗口（自动分配）」再开一个独立窗口（也可直接再运行一次程序）；标题带 `(2)` / `(3)` 区分（任务栏、托盘同样带后缀）。
  - **配置互不覆盖** —— 每个窗口用各自的配置文件（主窗口 `settings.ini`，其余 `settings-2.ini` / `settings-3.ini`…），改设置、关窗口不再互相覆盖；靠文件锁自动分配空闲槽位，连**双击开两个**也会自动隔离（解决了以前"开两个窗口配置互相覆盖"的问题）。
  - **各自独立** —— 每个窗口有独立的连接、收发、自动应答、Modbus 主机、终端等状态，互不干扰（注意：同一个串口仍只能被一个窗口打开，第二个开同口会提示占用——这是正常的，数据不会串）。
- **打开配置（切换）** —— 「帮助 → 打开配置」列出已保存的配置（主配置 / 配置 2 / 配置 3…），点一个即把**当前窗口**切换到该配置（标题随之变 `(N)`，之后保存写回该配置）；正被别的窗口用的、当前窗口自己的会标注禁用。解决"全部关掉后想用回以前某套配置却没入口"。
- **删除配置** —— 「帮助 → 删除配置」删掉不再需要的配置文件（二次确认，默认焦点在「取消」防误删）；主配置、正在用的配置不可删。
- **多显示器兜底** —— 窗口若落到已断开 / 关闭的屏幕外，首次显示时自动搬回主屏，避免"进程在、窗口看不见"；同时可开窗口数上限为 8，开满后提示、不再新建。

## 🐞 修复

- **开着系统代理时连不上本机 / 局域网 TCP** —— 开了系统代理时，连本机或局域网的 TCP 服务器 / 客户端会失败（"代理类型无效"）；现在调试连接一律**直连、不走代理**（TCP / UDP 均已修）。
- **底部状态栏提示与统计文字重叠** —— 连接失败等提示不再和 RX / TX 统计叠在一起。
- **多窗口稳定性** —— 修复开第二个 / 新配置窗口时可能卡住只剩进程没界面、关窗口卡死等问题。
