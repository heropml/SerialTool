串口 + 网络一体调试工具。本版一次带来多项实用增强：**数值仪表盘、协议高亮、串口自动重连、USB 芯片识别**。

## 1. 数值仪表盘

菜单栏「功能 → 数值仪表盘」：把 RX 流按 **分隔符 / 正则 / HEX 字段** 解析成命名数值通道，每通道一张**大字号卡片**实时显示当前值。阈值行填 `名称:下限~上限:单位`（逗号分隔，如 `温度:10~40:℃, 电压:3.0~3.6:V`，上 / 下限可留空表示该侧不限），值超范围时卡片**变红闪烁**。适合 IoT 传感器 / 电源等实时读数监看；解析配置与波形图相互独立。

## 2. 协议高亮

「功能 → 帧解析」对话框勾选「协议高亮」后，主界面 **HEX 显示模式**下按帧解析规则给收到的每帧各字段**上色**（从机地址 / 功能码 / CRC 各一色），鼠标悬浮任一色块弹出「规则 · 字段=值」解析。让数据区从「原始字节流」升级为「结构化信息流」，复用帧解析已有的规则、无需另配一套。

## 3. 串口自动重连

串口运行时掉线（拔出 / 断电 / 线缆抖动）自动重连，退避从 **0.5s 线性递增到 5s**，且**只回到掉线前那个设备与参数**——保存完整连接签名，绝不漂移到下拉框里回落选中的别的口；并等原端口重新枚举到系统才尝试。等待与实际重试共用 **最多 10 次（约 27.5s）** 的总窗口，仍未恢复则**静默放弃**、保持断开。**掉线时提示一次，之后自动重试静默不刷屏**，插回即自动连上。

## 4. USB 芯片识别

串口下拉在系统端口描述后补出 **USB-UART 转换芯片型号**（CH340 / CP2102 / FT232 等，按 VID/PID 匹配），同时插着多个 USB 转串口时一眼分清哪个口是哪个设备。
