**CommTool** — 开源串口调试助手 / 网络调试工具（UART + TCP/UDP）。**v1.5.6 正式版**：多会话引擎补齐——文件传输 / 回放 / 设备扫描 / 自动应答按标签独立，扫描表与录制捕获按会话隔离。

## v1.5.6 正式版

### 剩余引擎按会话独立
- **文件传输**：worker / 连接 / 目标 / 桥接钉在本会话；开始 / 停止 / 日志跟当前标签；关对话框取消所有会话的传输
- **回放**：播放状态与驱动 TX 钉在本会话；播放 / 停止跟当前标签；关对话框停止所有会话的回放
- **设备扫描**：不再整窗一次拒绝；各标签可各自扫，互不接管其它标签的主机轮询
- **自动应答**：开关按会话独立（窗口勾选跟当前标签）；后台 RX 仍喂本会话 AR
- 脚本 / Modbus 主机 / 序列：双标签可各跑一套；Run/Stop 跟当前标签；关脚本控制台结束全部 worker

### UI 按标签隔离
- **脚本控制台日志**按会话保存，切标签只看当前会话输出
- **设备扫描表**按会话保存扫描结果；后台会话的回调不再刷当前标签的表
- **录制捕获**按会话保存事件；停录 / 加载 / 切标签不再互相覆盖

### 修复
- 脚本后台 worker 结束时仍释放该会话的 I/O 钉住；过期 worker 不再误清当前标签
- 脚本超长截断后警告可在切换 / 加载 / 新建后重新触发
- 文件传输按真实文件大小确认（超过 100 MB 先询问）；完成回调不再阻塞 GUI 线程
- 后台 RX 异常列表不再吞掉 `AttributeError`；会话代理空上下文时调试记录丢弃写入
- 回放对话框关闭先停当前播放再停其余会话；去掉重复的对话框引用清理
- 会话代理属性与 `Session` 槽位启动时对拍，漏代理立刻失败

### 产品边界
- 本版不做会话树、拖拽分屏、标签拖出成窗
- P2（CLI / REST / 插件 dissector）继续暂缓
- macOS DMG 仍由协作者在 Mac 上跑 `release_macos.sh` 补到同一 Release；门禁通过前检查更新不提供 Mac 下载

### 测试
- 全量测试：1541 passed，11 skipped，295 subtests passed
