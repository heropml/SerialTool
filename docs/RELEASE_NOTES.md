**CommTool** 串口调试助手 / 网络调试工具支持 UART、RTT 和 TCP/UDP。v1.8.8 修复了串口与 RTT 同时使用时的日志漏记，并让终端命令和串口接收时间更容易核对。

## 终端输入与回显

- 发送区逐键显示当前命令。按回车或点「发送」都会发出所选的 CR、LF 或 CRLF，并清空当前行。切换标签时，各会话保留各自的输入和光标位置。
- 本地回显跟随退格、删除和光标编辑。中文输入法确认上屏的文字会发给设备。提交后，数据区和实时日志保留最终命令。
- 对单一设备在 1.5 秒内返回的匹配命令回显，终端支持分块匹配，避免重复显示和记入文本日志。原始收发录制保留设备实际返回的字节。

## 实时记录与重连

- 串口 HEX 与 RTT 终端可以同时记录。切换到另一标签后，后台会话继续把数据写入自己的文件。
- 重新打开界面后，首次启用「实时记录」即可选择文件。记录中手动断开连接会关闭当前文件，再次连上后会提示选择新文件。异步连接握手期间手动选定的文件也会生效。

## 串口计时、统计与回放

- 显示、日志与录制使用串口后台读取的时间戳。界面延迟处理 RX 时，录制按事件时间排入接收数据，并保持与发送事件的先后关系。
- 时间分包和自动应答按相邻读取的间隔判断，统一了恰好 20 ms 时的边界计算。串口时间戳反映主机读到数据的时刻，无法测量每个字节在线路上的到达时间。
- 串口 RX 统计分别显示读取块数、时间分包数和已解析的协议帧数。悬停可区分字节吞吐率、块速率及各自峰值。

## 验证与兼容性

- Windows 全量自动化测试通过 1896 项，跳过 37 项，另有 295 个子测试通过。包内代码通过 10 项专项回归，覆盖终端编辑、回显、日志选择及会话切换等场景。
- 沿用现有工程和录制格式。RTT 连接需安装 SEGGER J-Link 驱动。
