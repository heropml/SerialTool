串口 + 网络一体调试工具。本版新增**自动化测试序列**——把一组「发送 → 等回包匹配」步骤按顺序自动跑一遍、逐步判定**通过 / 失败**并出汇总，适合出厂测试、设备自检、批量验机、协议联调等重复动作。

## 1. 自动化测试序列

菜单栏「功能 → 自动化序列」打开。每步可配：名称、发送内容（文本 / HEX）、校验（CRC / 累加和等自动追加，同主界面）、期望回包（**留空 = 纯发送、不等回包**）、匹配模式（包含 / 相等 / 前缀）、超时 ms、超时动作（**停止** = 该步失败即整体结束 /**继续** = 记失败但继续往下跑）、步间延时 ms。按顺序发送、等回包并按模式判定，结果列实时刷 待运行 → 等回包… → **✓ 通过 / ✗ 超时**，全部跑完给出通过 / 失败汇总。

## 2. 运行隔离

序列是主动驱动方，运行期间自动**暂停「自动应答」与「Modbus 主机」**（三者共用收流），序列结束自动恢复；连接断开会**中止序列并保留已跑结果**。

## 3. 数据列可拖

每步一行卡片，只有「发送」「期望回包」两个数据框可左右拖宽、其余列固定（形制同自动应答对话框），长内容看得全。

## 4. 运行态指示

运行中「运行」按钮变绿、锁定增删行防边跑边改，步骤自动保存；带「?」用法说明弹窗（含 AT 指令 / Modbus 读寄存器 / 纯发送三个示例）。**无新依赖**。
