串口 + 网络一体调试工具。本版新增**桥接转发**——把任意两个端点（串口 / TCP 客户端 / TCP 服务端 / UDP）连起来双向原样透传，做协议中转、设备联网、旁路抓流。

## 1. 两端任意组合双向透传

菜单栏「功能 → 桥接」：A / B 两端各自独立选 **串口 / TCP 客户端 / TCP 服务端 / UDP**，连通后双向原样透传字节——**串口↔串口、串口↔网络、网络↔网络任意组合**。典型用法：把只有串口的设备接进以太网、两段协议中转、旁路抓流分析。

## 2. 稳健的转发引擎

任一侧断开 / 出错**自动停桥**；实时显示 A→B / B→A 收发字节数与速率。发送做了加固：TCP 服务端**多客户端广播** + 待发缓冲背压（部分写即判帧损坏、踢掉该客户端）、UDP **按 65507 拆合法数据报**、发送失败**边沿触发上报**（进日志、不刷屏、不静默丢数据）；开桥前先检查两端**是否已有可发送目标**（TCP 需已连接 / UDP 需有对端），没就绪明确提示而非白开。

## 3. 转发日志

底部可开「转发日志」：**文本 / HEX** 双模式、可清空、行数上限可调；**增量 UTF-8 解码**（跨包的多字节字符不再乱码）、单条字节上限防大包刷爆。

## 4. 对话框 UI 打磨

各对话框下拉框补上下拉箭头（此前看着像文本框）、**禁用输入框变灰**（如 UDP「指定远程」关闭时的远程地址）；桥接「指定远程」改用与主界面一致的拨动开关。
