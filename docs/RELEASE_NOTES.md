串口 + 网络一体调试工具。本版一次带来多项实用增强：**工具箱**（进制转换 + 校验计算）、**功能菜单重组**、**串口控制线**（DTR/RTS/复位/Break + 硬件流控 + 输入状态灯）、**文件传输**（XMODEM/YMODEM + 原始字节流）、**HEX 转储视图**。

## 1. 工具箱（进制转换 + 校验计算）

菜单栏「功能 → 工具箱」。进制/编码转换：字节序列在 HEX ⇄ 文本 ⇄ 十进制 ⇄ 二进制间实时互转（改一处其余同步、非法标红），并把该串按 ascii/u16/i16/u32/i32/f32 解释（可选大小端）；单值多进制 十进制/HEX/二进制/八进制（位宽 8/16/32/64 + 有无符号，负数按补码）+ 位掩码（哪些位置 1，可编辑回填）。校验计算：输入 HEX 或文本，一次性列出全部内置校验算法结果，贴数据段看哪行 == 帧尾校验即可反推算法；另附自定义 CRC（Rocksoft 参数：宽度/多项式/初值/异或/输入输出反转/字节序）。

## 2. 功能菜单重组

波形图、帧解析、Modbus 主机从数据区工具栏移入标题栏「功能」菜单，与帧构造器 / 自动化序列 / 工具箱统一带序号排列；数据区工具栏精简，只留 关键字高亮 / 只显高亮行 / 字号。Modbus 主机保持末位、轮询开启时菜单项末尾显示「●」。

## 3. 串口控制线（DTR/RTS + 复位 + Break + 硬件流控 + 状态灯）

打开串口后，「打开串口」按钮下方出现「控制线」小节：**DTR / RTS** 两个输出开关手动拉高 / 拉低（复位 MCU、控制外设使能等）；**复位** 按钮把 DTR 拉低约 120ms 再恢复，触发多数 Arduino / ESP 的自动复位；**中断(Break)** 按钮拉低 TX ~250ms，常用于唤醒设备、触发进入 bootloader；**CTS / DSR / DCD / RI** 四个只读状态灯以 ~5Hz 轮询显示输入线电平（绿 = 有效）。串口设置区新增 **流控** 下拉（无 / RTS-CTS 硬件 / XON-XOFF 软件），选硬件流控时自动禁用手动 RTS。DTR / RTS 状态随会话配置持久化。

## 4. 文件传输（XMODEM / XMODEM-1K / YMODEM + 原始字节流）

菜单栏「功能 → 文件传输」。支持 **XMODEM**（128 字节，校验和 / CRC）、**XMODEM-1K**、**YMODEM**（带文件名 / 大小）三种协议的收发双向，常用于向 bootloader 上传固件；另有 **原始字节流** 模式把文件字节按可配「分块大小 + 块间延时」直接发出（不走协议、单向）。进度条 + 日志 + 取消 + 用法说明；传输期间数据区暂停显示、自动应答 / 序列 / Modbus 主机暂停。

## 5. 数据区 HEX 转储视图

数据区显示选项新增 **HEX 转储** 开关：收发数据按 hex 编辑器风格渲染 —— **偏移(8 位) + HEX(每行 8 / 16 / 32 / 64 字节可选、半程加宽中缝) + |ASCII|** 三列；每个数据块独立转储（偏移从 0 起），开时间戳时时间戳 / 箭头单独成行使各行纵向对齐。开启时接管 HEX 显示（灰掉该开关，明确优先级）；与「只显高亮行」过滤联动，时间戳装饰行始终可见。
