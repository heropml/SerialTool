**CommTool** — 开源串口调试助手 / 网络调试工具（UART + RTT + TCP/UDP）。**v1.8.1 正式版**：侧栏自动隐藏与浮层交互修复。

## v1.8.1 正式版

### 侧栏自动隐藏

- 连接设置标题右侧新增图钉，整条侧栏可在固定分栏与自动隐藏之间切换，为数据区腾出空间。
- 自动隐藏后左缘显示竖标签；悬停或点击可展开浮层，鼠标移开约半秒收回，再点图钉恢复固定。
- 编辑输入框、下拉弹窗和模态对话框交互期间保持展开。
- 保存自动隐藏偏好与摘出前的分隔条状态，重启恢复布局；三语文字、提示和图标颜色跟随语言与主题切换。

### 交互修复

- 鼠标快速扫过竖标签时取消延迟展开，避免误弹出遮挡数据区。
- 切换工作台分类时显式关闭浮层，修复切回终端后浮层重新出现且无法自动收回的问题。
- 补强侧栏测试，覆盖快速扫过、重新悬停、切页显式隐藏及切回后保持关闭。

### 文档与兼容性

- README、简体中文 / 繁體中文 / English 用户说明、架构与排期同步侧栏操作及发布状态。
- 默认仍为固定侧栏；连接协议、收发和已有配置格式保持原有行为。

### 发布范围

- 本次发布 **Windows 安装版和单文件版**，tag 为 `comm-v1.8.1`。
- macOS（Apple Silicon）和 Linux x86_64 本版本待补包，更新清单暂不提供对应的新版本自动下载地址。
