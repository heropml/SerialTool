串口 + 网络一体调试工具。本版围绕「日志更像终端、异常主动提醒、常用命令随手取用」：**ANSI 彩色显示、触发告警、发送模板库、显示方式整合**。

## 1. ANSI 彩色显示

ESP-IDF / Zephyr / U-Boot 等固件自带的彩色日志现在可在数据区按原色显示。支持 SGR 基础色、亮色、256 色、真彩，以及粗体、下划线和反显；深浅主题分别使用可读调色板。

颜色和未收完的转义序列支持跨包延续，TCP Server 各客户端独立维护状态。光标移动、擦除、窗口标题等非显示序列会被吃掉，不再出现 `^[[0;32m` 一类乱码。

## 2. 触发告警

功能菜单新增「触发告警」：可按文本或 HEX 配置**包含 / 相等 / 前缀 / 正则**规则，并限定接收、发送或收发双方。命中后可响铃、弹托盘通知、在数据区打标。

冷却窗口只压制重复动作，命中次数和最后时间仍准确累计。串口/TCP 支持跨底层收包匹配完整关键字，UDP 不跨数据报拼接；正则会预编译，并拒绝明显可能卡住界面的灾难性回溯结构。

## 3. 发送模板库

在「多条发送」窗口顶部打开模板库，把常用 AT 命令、复位帧、Modbus 请求等保存为文本或 HEX 模板。支持搜索、增删、JSON 导入导出、双击填入发送框，以及「填入并发送」。

模板直接复用主窗口发送路径，所以换行、校验、发送目标等设置与手动发送一致。编辑自动去抖保存，模板数量和字段长度均有上限，损坏配置安全回退。

## 4. 显示方式整合

文本、HEX、HEX 转储、数值四种渲染方式合并为一个互斥下拉，避免多个显示开关同时开启造成界面状态与实际渲染不一致。文本模式显示 ANSI 开关，转储模式显示每行宽度，数值模式显示类型与字节序。
