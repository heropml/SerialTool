串口 + 网络一体调试工具。本版围绕「连接可复用、用例可批量、结果可交付」，并把 Modbus 模拟与记录回放做深：**具名连接预设、序列变量与 CSV 数据驱动、HTML/CSV/JUnit 测试报告、收发统计与诊断增强、Modbus 多从机 / 异常注入 / 新功能码（08/11/17/23）、图表持久化与会话差异分析**。

## 1. 具名连接预设

连接栏新增预设下拉与「保存 / 管理」：把串口或网络的全部参数、备注和自动重连策略存成具名预设，支持最近使用排序、复制、删除和 JSON 导入导出，并随 `.ctproj` 工程打包。已连接时应用预设会被拒绝并回退占位项，避免连接中被改参数。

## 2. 序列变量与 CSV 数据驱动

自动化序列的「发送」「期望回包」支持 `${name}` 模板，每步可从回包按文本、HEX、正则分组或 Modbus 字段提取变量供后续步骤使用，变量作用域按单轮隔离，`$${` 转义为字面 `${`。未定义变量不再静默降级成纯发送，而是当步失败，避免循环老化出现假通过。

序列可绑定 CSV 数据集：每行参数跑一轮，表头作为 `${var}` 种子，轮数取行数；报告关联 CSV 行号与设备标识。CSV 依次按 utf-8、GBK（Excel 另存）、latin-1 回退解码。

## 3. 测试报告与 CI 产物

「导出报告」新增 **JUnit XML**，可直接被 Jenkins、GitLab CI 等流水线收集，HTML 与 CSV 保留。三种格式统一补充软件版本、开始与结束时间、测试参数（轮数、步骤数、失败即停）和 CSV 路径，每步记录耗时、失败原因和关键收发帧（TX / RX HEX）。

> 行为变更：**中途停止或断连也会出汇总并可导出**（报告标记为已停止），不再像旧版那样丢弃残缺结果；多轮运行的报告会逐轮展开每一步明细。

## 4. 收发统计与诊断增强

状态栏 RX/TX 增加包速率（pkt/s，「包」指底层收发块而非协议帧）；悬浮提示补充峰值包速、包大小 min/avg/max、大小分布直方图、序列 / Modbus 主机 / 连接三类超时次数以及近 1 分钟均速。波形图可订阅 `rx_Bps`、`tx_Bps`、`rx_pps`、`tx_pps` 四个吞吐通道。统计可一键重置，不影响记录与数据区。

## 5. Modbus 专业化：多从机、异常注入与新功能码

自动应答的 Modbus 从机可以在同一条总线上模拟多个从机：「多从机 JSON 列表」里一个条目一个从机，各自给寄存器表和从机 ID，没写的项按上方的单从机配置继承，填了这个框就以它为准、覆盖上面的单地址表。TCP Server 下每个客户端仍各自维护半包缓冲；广播地址 0 只接受写功能码，读以及 FC08 / FC11 / FC17 / FC23 会被拒绝并提示。

功能码下拉新增 **08 诊断(回显)**、**11 通信事件计数**、**17 报告从机 ID**、**23 读写多寄存器**，主机与从机两侧都实现。FC23 在数量列按 `读数量 @ 写地址 : 写入值` 填（如 `2 @ 100 : 10 20`）；FC08 的诊断数据填同一列，结果同时给出十进制与十六进制便于逐位对照。FC17 的从机 ID 长度未标准化，响应变长：RTU 按字节数字段取帧、Modbus-TCP 按 MBAP 长度字段、ASCII 按帧尾定界。

从机还可以按策略返回异常码来验证主机的异常处理分支，寄存器值可以按递增、递减、随机、正弦、斜坡自动变化以模拟真实设备状态，主机写入的值会覆盖动态值直到会话重置。

> 界面上目前只有「异常码」和「注入异常」开关。注入模式（`always` / `once` / `n`）、功能码与地址过滤、动态寄存器规则以及 FC08 子功能暂时没有界面，需要写在工程文件里，例如 `{"exception": {"enabled": true, "code": 4, "mode": "n", "n": 3, "funcs": [3, 6]}, "dynamics": [{"space": "holding", "addr": 0, "mode": "sine", "min": 0, "max": 100, "period_ms": 2000}]}`。

## 6. 记录回放与会话差异

波形图和仪表盘的数据源、单位与布局随 `.ctproj` 工程保存，重开工程即恢复。结构化记录可以按原时间轴回放并驱动同一套图表，支持暂停、单步、倍速与进度定位；`.ctrec` 字节级回放同样支持暂停、单步和按秒定位，单步会自动先暂停，保证每点一次只前进一个事件。

会话比较结果可以按方向（RX / TX）和时间差绝对值筛选，汇总计数跟着当前筛选结果走；筛选后的行可导出 CSV 或 JSONL，筛到一行不剩时导出按钮会自动禁用，不会产出只有表头的空文件。
