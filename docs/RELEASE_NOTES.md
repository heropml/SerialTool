串口 + 网络一体调试工具。本版把**自动化测试序列**做成能上产线的样子：一次配置，循环老化、失败重试、跑完出报告、用例可存档复用。

## 1. 测试报告导出（HTML / CSV）

跑完序列点「导出报告」：**HTML**(带通过/失败底色、汇总结论、测试时间，可直接存档/发邮件) 或 **CSV**(Excel 可开，已防 `=`/`+`/`@` 公式注入)。循环运行出「按轮次」表、单次出「按步骤」表。只有正常收尾(有汇总)才可导，停止/断连的残缺结果不导成缺结论的报告。

## 2. 循环运行（老化 / 可靠性测试）

顶栏可设「循环」次数(整条序列跑几轮，≥1) +「失败即停」：让设备连续自检 N 轮做老化/可靠性验证。运行中显示 第 R/N 轮 · 第 i/n 步；汇总给「通过轮 R/N + 累计步 X/Y」，提前停止会标出「计划 M 轮」避免误读。**中途停止/断连也为已跑轮出汇总**，长时间老化不白跑、结果可导报告。

## 3. 步骤级重试

每步可配「重试」次数(0=不重试)：失败(超时/发送失败)后，等本步延时 + 线路连续静默一小段再重发，任一次通过即算过，结果标「(第N次)」。上一次尝试的**迟到响应不会污染下一次**匹配；静默等待有上限，对端狂刷数据也不会卡死。

## 4. 步骤导入 / 导出（JSON）

「步骤 ▾」把整条序列导出 / 导入 **JSON**，便于分享、版本管理测试用例。导入严格校验(1–500 步、字段类型与范围、限 5MB)、覆盖当前用例前二次确认，防误导入丢失。
