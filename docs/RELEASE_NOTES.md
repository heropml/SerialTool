**CommTool** — 开源串口调试助手 / 网络调试工具（UART + TCP/UDP）。**v1.5.5 正式版**：多会话引擎收口——软切标签、后台 RX 喂本会话引擎、序列与 Modbus 从机 bank 按会话独立。

## v1.5.5 正式版

### 软切标签
- 独占引擎钉在启动时的会话：切到其它标签不再被硬拦，后台任务继续跑
- 关闭仍在跑任务的标签会拦截，标签悬停提示当前占用（`session_tip_engine_busy`）
- 定时发送、多条循环发送仍按会话独立，切标签后台继续

### 后台 RX 喂本会话引擎
- 非活动标签收到的数据会喂给该会话钉住的引擎（自动应答、序列、脚本/传输等占用方）
- 绘图、组帧、仪表盘、触发器仍只跟活动标签，避免后台噪声刷当前视图

### 按会话独立的运行态
- **序列**：每个标签可各自跑一套序列（独立定时器与回调）
- **Modbus 从机 bank**：每个会话一份寄存器；窗口共享从机配置，改配置时重建全部会话 bank
- **自动应答**仍为窗口开关，命中后按本会话发出

### 整窗一份、钉会话的工具
- 脚本控制台、文件传输、Modbus 主机、回放、发送 DSL、录制、宏、设备扫描：同窗各一份，钉在启动会话
- 文件传输运行中，其它标签点「开始」会被窗口级门禁拦住，避免把正在跑的 worker 撕走
- 序列「停止」只停当前标签自己的那一轮

### 产品边界
- 本版不做会话树、拖拽分屏、标签拖出成窗
- 脚本 / Modbus 主机 / 录制仍是整窗一份（非每会话一份）
- P2（CLI / REST / 插件 dissector）继续暂缓
- macOS DMG 仍由协作者在 Mac 上跑 `release_macos.sh` 补到同一 Release；门禁通过前检查更新不提供 Mac 下载

### 测试
- 基线：既有套件 + 多会话软切 / 后台 RX / 序列与从机 bank / 传输启动门禁等新增用例（以 CI 为准）
