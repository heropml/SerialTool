# 需求确认

## 功能要求

- 自动应答首次合法命中不得受冷却抑制；冷却继续按会话隔离。
- 更新 manifest 支持平台包 SHA-256 与文件大小；缺少摘要时不得自动执行，仅允许用户转到发布页。
- Webhook 默认仅 HTTPS；请求前解析全部地址并拒绝非公网地址；禁止或逐跳校验重定向；保留显式兼容开关给可信局域网场景。
- 发行版写入有限大小的滚动诊断日志；提供脱敏诊断包导出核心。
- 构建依赖有可复现 constraints；CI 覆盖最低支持版本与发行版本。
- 首屏空状态提供 Virtual 演示、示例工程、最近工程三个快速入口。
- 操作面板、帧模板、录制会话索引先完成可持久化核心和最小 UI 入口，不引入云同步。
- 新策略优先放 Qt-free 模块并配纯逻辑单测。

## 非功能要求

- 不破坏现有 `.ctproj`、`latest.json` 旧格式读取和三语 UI。
- 不把用户通信载荷写入诊断日志；诊断包需脱敏路径和地址。
- 不新增必须联网的运行时依赖。
- 保持 Python 3.11/3.12 为发行基线；Qt 6 本轮只建立迁移检查，不全量切换。
